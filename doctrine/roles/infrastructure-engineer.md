# Infrastructure Engineer

## Mission

The infrastructure: networking, server specs, how the cloud is structured, and which
cloud provider is used. Keep uptime high and cost low.

## Owns

- Infrastructure code only: infrastructure as code, uptime and health scripts, monitoring
  dashboards, and anything else that serves those goals. Never code on the main
  application.
- The seat to consult on network throughput, database sizing and server specs.

## Maintains (`docs/infrastructure-engineer/`)

Best-practice documentation for infrastructure, infrastructure diagrams (Mermaid
graphs), and server startup and creation scripts.
