# New Project

- **Module:** new-project
- **Version:** 1
- **Governs:** what starting a project asks for and what it sets up.
- **Depends on:** staffing, standards, budgets, documentation, communication.
- **Settings:** the defaults in `config/`.

**Every step can be done through ordinary forms, without an agent.** The XO is a helper,
never a requirement. Every field after the name is pre-filled with a default, so a name, a
PRD and Create is enough.

## The form, in order

1. **Name.**
2. **Repo:** a new one, or an existing one.
3. **PRD:** upload a file, paste it, write it in the PRD editor, or skip it.
   - If skipped, one optional box appears: **"What is this project?"**
   - The user then chooses: the XO grills them into a first PRD, or the Producer writes
     one. A Producer-written PRD lets the fleet **start working immediately**, and the
     project is marked "PRD generated by AI" until the user accepts or edits it.
4. **Language or languages.** If a chosen language has no section in the standards yet,
   the form offers, in this order:
   1. continue with only the language-neutral rules, recorded as a deviation;
   2. import a language section from a file;
   3. the XO runs the new-language procedure with the user as a short grill;
   4. the XO writes a suggested section on its own.
5. **Standards profile:** full, prototype, or one of the user's own. **Forced to "one of
   your own" when a chosen language has no section**, because the result is necessarily
   the user's own.
6. **Starting seats** as checkboxes, and the **at-will box** (off by default).
7. **Harness per seat.** It comes before the model because it decides which models are
   available.
8. **Model per seat**, defaulting to Opus or an equivalent.
9. **Project cap.** Raisable later from the project's settings.

## On Create

- The project's board project is created.
- The repo gets its `docs/` skeleton (`modules/documentation/`).
- **For an existing repo**, a baseline of current standards violations is recorded. New
  violations are blocked, and any file a change touches must drop its old violations too.
  The baseline count shows on the project's node so the user can watch it shrink.
- The fleet starts once a PRD exists, including one marked "PRD generated by AI".

## Later

Every field stays editable from the project's settings, versioned with who, why and what
changed. Changing seats still goes through `modules/staffing/`.
