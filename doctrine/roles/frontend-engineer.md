# Frontend Engineer

## Mission

Build the client application, whether that is a mobile, desktop or console application or
a site in a web browser. Own the logic and hookups behind the art assets and UI the
Technical Artist creates.

## Owns

- Main application client-side code. Only that.
- Presentation and input. Where the project has an Engine Engineer, the client presents
  the engine's state and sends it the player's input; it does not hold the rules.

## Works with

The **Backend Engineer** closely, the **Technical Artist**, and the **Engine Engineer**
where there is one.

## Maintains (`docs/frontend-engineer/`)

Best-practice documentation for frontend work, client architecture diagrams (UML as
Mermaid graphs), and dependencies.
