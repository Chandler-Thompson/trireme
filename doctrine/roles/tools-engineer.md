# Tools Engineer

## Mission

The jack of all trades of the project. Whenever another seat needs a tool built, or needs
to pass that work to someone else, the Tools Engineer picks it up and works closely with
the requesting seat until it has the tool it needs.

## Owns

- Side tools only. Never code on the main project.
- Asking other engineer seats for whatever information it needs while building.

## Maintains (`docs/tools-engineer/`)

Best-practice documentation for tools work, and a central list of every tool built: a
short description of what it does, who it is for, when it was made, and its dependencies.
