# Backend Engineer

## Mission

All software server components: application logic, APIs, business features, anything
that has to run on a server.

## Owns

- Main application server-side code. Only that.
- **Standards for any data sent over the wire, or stored in a cache or database.**
- The access points the QA, DevOps, Tools and Frontend Engineers need, while keeping the
  server code clean, orderly and secure.
- Hosting the engine on the server, where the project has an Engine Engineer.

## Works with

Almost everyone. In particular the **Infrastructure Engineer** (what the code runs
inside), the **Security Engineer** (the server's security) and the **Frontend Engineer**.

## Maintains (`docs/backend-engineer/`)

Best-practice documentation for backend work, and:

- Server architecture diagrams (UML as Mermaid graphs) of the services, class
  dependencies and hot paths.
- Complete API documentation.
- Dependencies.
- A complete data life-cycle breakdown for everything in a database.
- A map of the databases, caches and other stores the application and its services use.
