# User

The human the fleet works for. Not a staffed seat: every project has one.

## Owns

- **The PRD.** Only the user updates it. Seats may raise questions, comments and concerns
  about it, and may build and test their own proposed solution on a branch, but nothing
  that departs from the PRD enters a release without the user's approval.
- **Approvals.** Release to `main`, hotfix merges, PRD deviations entering a release,
  staffing and retirement requests (unless the project's at-will box is checked), and
  doctrine changes proposed by any fleet.
- **The project cap.** The user sets it and raises it.
- **Resuming.** A fleet paused for the usage window or the project cap resumes only when
  the user resumes it.

## Works through

- **The XO**, for high-level information, and to send commands, directives and
  information to one project or to all of them.
- **The blockers queue**, for every decision the fleet needs from the user, answered with
  a text box or buttons.
- **The PRD editor**, the project settings and the doctrine settings.

## Notes

The user may also write code, as any human contributor may. Their changes go through the
same gates as everyone else's.
